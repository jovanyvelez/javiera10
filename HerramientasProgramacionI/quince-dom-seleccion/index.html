🌳 ¿Qué es el DOM?

⏱️ 35 minutos · "El árbol de la página" — cómo el navegador convierte tu HTML en un objeto

🧠 La idea central

Cuando el navegador carga tu HTML, no lo guarda como texto plano: lo convierte en un árbol de objetos llamado DOM (Document Object Model, "Modelo de Objetos del Documento"). Cada etiqueta se vuelve un nodo del árbol, y JavaScript puede leer y modificar esos nodos en tiempo real.

Por eso, cuando cambias algo con JavaScript, la página se actualiza al instante, sin recargar. El HTML original no cambia: cambia el DOM que el navegador tiene en memoria.

📄 HTML (el archivo)

Es el texto que escribes en tu editor. Estático: no cambia solo. Es la "receta" de la página.

🌳 DOM (en memoria)

Es la versión viva de esa receta, convertida en un árbol de nodos. JavaScript puede modificarla al vuelo.

💡 ¿Por qué importa?

🎯 Seleccionar elementos

⏱️ 35 minutos · "Encontrar el nodo correcto" — getElementById, querySelector y querySelectorAll

🧠 La idea central

Para modificar un elemento, primero hay que encontrarlo. JavaScript te da varios métodos para "agarrar" nodos del DOM. Los tres más usados son getElementById(), querySelector() y querySelectorAll().

🔍 Los tres buscadores

MétodoQué buscaQué devuelve
getElementById('x')Un elemento por su idUn solo elemento (o null)
querySelector('.clase')El primer elemento que coincide con un selector CSSUn solo elemento (o null)
querySelectorAll('li')Todos los elementos que coinciden con un selector CSSUna lista (NodeList)

✏️ Modificar contenido

⏱️ 35 minutos · "Cambiar lo que dice la página" — textContent e innerHTML

🧠 La idea central

Una vez que seleccionaste un elemento, puedes cambiar lo que muestra. Hay dos formas principales: textContent (cambia solo el texto) e innerHTML (cambia el HTML interno, incluyendo etiquetas).

🔤 textContent

Cambia solo el texto. Si le pasas etiquetas, las muestra como texto literal. Más seguro y rápido.

el.textContent = 'Hola';

🧩 innerHTML

Cambia el HTML interno. Puedes insertar etiquetas nuevas, pero ten cuidado con contenido no confiable.

el.innerHTML = '<strong>Hola</strong>';

🎨 Modificar clases y atributos

⏱️ 35 minutos · "Cambiar el estilo y los atributos" — classList y setAttribute

🧠 La idea central

Además del contenido, puedes cambiar el estilo (agregando o quitando clases CSS) y los atributos (como src, href o disabled). Para las clases usas classList; para los atributos, setAttribute().

🎨 classList: los tres comandos

MétodoQué hace
classList.add('x')Agrega la clase x
classList.remove('x')Quita la clase x
classList.toggle('x')La agrega si no está, la quita si está (interruptor)

🔧 Modificar atributos

Para cambiar un atributo usas setAttribute('nombre', 'valor'). Por ejemplo, cambiar el src de una imagen o el href de un enlace.

atributos.js
// Cambiar el src de una imagen
const img = document.querySelector('img');
img.setAttribute('src', 'nueva-imagen.jpg');

// Cambiar el href de un enlace
const enlace = document.querySelector('a');
enlace.setAttribute('href', 'https://otra-pagina.com');

// Deshabilitar un botón
const boton = document.querySelector('button');
boton.setAttribute('disabled', '');

➕ Crear elementos

⏱️ 35 minutos · "Fabricar nodos nuevos" — createElement, append y appendChild

🧠 La idea central

No solo puedes modificar lo que ya existe: también puedes crear elementos nuevos desde cero y agregarlos a la página. Con createElement() fabricas el nodo, y con append() o appendChild() lo insertas en el DOM.

📋 La receta para crear un elemento

crear.js
// 1. Crear el elemento
const li = document.createElement('li');

// 2. Darle contenido
li.textContent = 'Nueva tarea';

// 3. Agregarlo a la lista
const lista = document.querySelector('ul');
lista.append(li);

💡 Pro-Tip: DocumentFragment

Si vas a agregar muchos elementos a la vez, usa un DocumentFragment: es un contenedor temporal que agrupa nodos y los inserta todos de una sola vez, más eficiente que agregar uno por uno.

🧩 Bloque C — Renderiza: un <li> por cada tarea

El corazón del miniproyecto: un ciclo recorre el array, fabrica un <li> con createElement, le pone su texto con textContent y lo agrega a la lista con append. Sin recargar la página.

clase15-dom/app.js — bloque C
// C. Crea un <li> por cada tarea y agrégalo a la lista
const lista = document.getElementById('lista-tareas');
for (let i = 0; i < tareas.length; i++) {
  const li = document.createElement('li');
  li.textContent = tareas[i];
  lista.append(li);
}

🧩 Bloque D — Marca una completada y cuenta el total

querySelector toma la primera tarea, classList la marca como completada, y querySelectorAll + textContent actualizan el contador.

clase15-dom/app.js — bloque D
// D. Marca una tarea como completada y cuenta el total
const primera = document.querySelector('#lista-tareas li');
primera.classList.add('completada');

const todas = document.querySelectorAll('#lista-tareas li');
const contador = document.getElementById('contador');
contador.textContent = 'Tienes ' + todas.length + ' tareas en total';
