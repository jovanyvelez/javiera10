📝 La etiqueta form y sus partes

⏱️ 35 minutos · "La puerta de entrada de datos" — form, label, input, textarea, select, button

🧠 La idea central

Un formulario es la forma en que una página recibe información del usuario: su nombre, su correo, un mensaje, una contraseña. Todo vive dentro de la etiqueta <form>, que es el contenedor. Dentro de ella van los campos: cada uno con su etiqueta y su control de entrada.

Piensa en un formulario de papel: tiene un título, campos con su nombre ("Nombre:", "Correo:") y espacios para escribir. En HTML es igual, pero con etiquetas.

⌨️ Tipos de input

⏱️ 35 minutos · "Cada dato tiene su campo" — text, email, password, number, date, checkbox, radio

🧠 La idea central

La etiqueta <input> es una sola, pero cambia de forma según su atributo type. Un type="text" es una caja de texto, un type="password" oculta lo que escribes, y un type="checkbox" es una casilla. Elegir el tipo correcto hace el formulario más fácil de usar.

☑️ checkbox — varias opciones

Casillas de verificación. El usuario puede marcar varias a la vez. Ideal para "¿qué te gusta?" con varias respuestas.

🔘 radio — una sola opción

Botones de opción. El usuario elige solo una de un grupo. Ideal para "elige tu género" o "elige un plan".

⚠️ Error común: confundir checkbox y radio

Si el usuario puede elegir varias opciones, usa checkbox. Si debe elegir solo una, usa radio (y dale el mismo name a todas las del grupo para que se excluyan entre sí).

♿ label y accesibilidad

⏱️ 35 minutos · "Un formulario para todos" — relacionar label con input, tabulación, contraste, foco

🧠 La idea central

Un formulario accesible es uno que cualquier persona puede usar, incluida una persona ciega que usa un lector de pantalla. La clave está en la etiqueta <label>: cuando la relacionas con su campo, el lector de pantalla puede decir "Nombre, campo de texto" en lugar de solo "campo de texto".

🔗 Cómo relacionar label con input

Hay dos formas. La más recomendada es usar el atributo for en el <label> y el atributo id en el <input>, con el mismo valor.

accesible.html
<!-- ✅ Accesible: label relacionado con input -->
<label for="nombre">Nombre:</label>
<input type="text" id="nombre" name="nombre">

<!-- ❌ Inaccesible: input sin label -->
<input type="text" name="nombre">

💡 Las 4 reglas de accesibilidad

(1) Relaciona cada label con su campo. (2) Mantén un orden lógico de tabulación: al presionar Tab, el foco debe ir de arriba a abajo. (3) Usa contraste suficiente entre texto y fondo. (4) Asegura un foco visible: que se vea claramente qué campo está seleccionado.

📬 Construye un formulario de contacto

⏱️ 35 minutos · "Manos a la obra" — un formulario completo y accesible

🎯 La misión

Un formulario de contacto es el clásico de toda página: nombre, correo y mensaje. Vas a armarlo con todas las piezas que viste: <form>, <label>, <input>, <textarea> y <button>, con accesibilidad y validación.

💻 El formulario de contacto completo

contacto.html
<form>
  <label for="nombre">Nombre:</label>
  <input type="text" id="nombre" name="nombre" required>

  <label for="correo">Correo:</label>
  <input type="email" id="correo" name="correo" required>

  <label for="mensaje">Mensaje:</label>
  <textarea id="mensaje" name="mensaje" required></textarea>

  <button type="submit">Enviar</button>
</form>

💡 El atributo required

El atributo required le dice al navegador: "este campo no puede ir vacío". Si el usuario intenta enviar sin llenarlo, el navegador muestra un aviso y no envía. Es validación sin escribir una sola línea de JavaScript.

✅ Construye un formulario de tareas

⏱️ 35 minutos · "Tu proyecto toma forma" — título, descripción, categoría y estado

🎯 La misión

Ahora un formulario más completo: para agregar una tarea a tu proyecto. Tiene un título, una descripción, una categoría (con <select>) y un estado (con radio). Aquí combinas todo lo aprendido.

💻 El formulario de tareas completo

tareas.html
<form>
  <label for="titulo">Título:</label>
  <input type="text" id="titulo" name="titulo" required>

  <label for="descripcion">Descripción:</label>
  <textarea id="descripcion" name="descripcion"></textarea>

  <label for="categoria">Categoría:</label>
  <select id="categoria" name="categoria">
    <option value="casa">Casa</option>
    <option value="colegio">Colegio</option>
    <option value="personal">Personal</option>
  </select>

  <p>Estado:</p>
  <input type="radio" id="pendiente" name="estado" value="pendiente">
  <label for="pendiente">Pendiente</label>
  <input type="radio" id="hecha" name="estado" value="hecha">
  <label for="hecha">Hecha</label>

  <button type="submit">Agregar tarea</button>
</form>

⚠️ El atributo name en los radio

Fíjate que los dos radio de "estado" tienen el mismo name="estado". Eso es lo que los agrupa: al elegir uno, el otro se desmarca automáticamente. Si tuvieran name distintos, podrías marcar los dos a la vez.

⚠️ Tu formulario todavía NO guarda nada
