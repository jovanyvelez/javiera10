🎨 ¿Qué es CSS y cómo se incluye?

⏱️ 35 minutos · "La ropa de la página" — por qué separamos presentación y estructura

🧠 La idea central

Imagina que HTML es el esqueleto de una persona y CSS es su ropa: el color de la camisa, el tamaño de las letras, el espacio entre los párrafos. CSS significa Cascading Style Sheets (hojas de estilo en cascada) y sirve para controlar cómo se ve la página, sin tocar su estructura.

La gran ventaja: si cambias una regla de CSS, cambia el estilo de toda la página a la vez. Separar presentación (CSS) de estructura (HTML) hace tu código más limpio y fácil de mantener.

📦 Las 3 formas de incluir CSS

FormaDónde vaCuándo usarla
<link> externoEn el <head>, apunta a un archivo .cssLa recomendada: reutilizable en varias páginas
Interno <style>Dentro del <head> de la misma páginaPara una sola página pequeña
En línea style=""En el atributo de una etiquetaCasos puntuales; evítalo en general

🎯 Selectores

⏱️ 35 minutos · "A quién le pones la ropa" — etiqueta, clase, id y universal

🧠 La idea central

Un selector le dice a CSS a qué elementos aplicar un estilo. Es como elegir a quién le pones la ropa: ¿a todos los párrafos? ¿a los que tienen una clase? ¿a uno solo con un id? Hay cuatro selectores básicos que debes dominar.

🎯 Los 4 selectores básicos

SelectorSintaxisQué selecciona
Etiquetap { }Todos los elementos de esa etiqueta
Clase.destacado { }Todos los elementos con esa clase
Id#titulo { }Un único elemento con ese id
Universal* { }Todos los elementos de la página

⚠️ Error común: id repetido

El id debe ser único en toda la página: solo un elemento puede tener id="titulo". Si necesitas estilizar varios elementos, usa una clase (class="..."), que sí puede repetirse.

🌈 Colores

⏱️ 35 minutos · "Pintar la página" — nombres, hexadecimal, RGB y HSL

🧠 La idea central

En CSS puedes escribir un color de cuatro maneras distintas. Todas producen el mismo resultado visual, pero cada una tiene su momento. Conocerlas te permite leer y escribir cualquier hoja de estilos.

🎨 Las 4 formas de escribir un color

RGBrgb(255, 0, 0)Cuando quieres controlar cada canal

🔤 Tipografía

⏱️ 35 minutos · "La letra importa" — font-family, font-size, font-weight y line-height

🧠 La idea central

La tipografía es el arte de elegir y ajustar las letras. En CSS controlas cuatro cosas principales: qué fuente usar, qué tamaño, qué grosor y cuánto espacio entre líneas. Una buena tipografía hace tu página legible y agradable.

🔤 Las 4 propiedades clave

PropiedadEjemploQué controla
font-familyfont-family: Arial;La fuente o tipo de letra
font-sizefont-size: 16px;El tamaño de la letra
font-weightfont-weight: bold;El grosor (normal, bold, 100-900)
line-heightline-height: 1.5;El espacio entre líneas

⚖️ Cascada y especificidad

⏱️ 35 minutos · "¿Quién gana?" — por qué una regla se impone sobre otra

🧠 La idea central

Cuando dos reglas de CSS apuntan al mismo elemento, ¿cuál gana? La respuesta está en dos conceptos: la cascada (el orden y origen de las reglas) y la especificidad (qué tan "específico" es un selector). Entender esto evita el clásico "¿por qué no se aplica mi estilo?".

⚖️ La escala de especificidad

De menor a mayor "poder", los selectores se ordenan así:

SelectorPoderEjemplo
EtiquetaBajop { color: blue; }
ClaseMedio.aviso { color: green; }
IdAlto#titulo { color: red; }
En líneaMáximo<p style="color: black">

🌊 Cascada

Si dos reglas tienen la misma especificidad, gana la que aparece después en el código. Es como una cascada: lo último que cae, se queda encima.

🎯 Especificidad

Si las reglas tienen distinta especificidad, gana la más específica, sin importar el orden. Un #id vence a una .clase, y una .clase vence a una etiqueta.

⚠️ El atajo peligroso: !important

Existe !important, que fuerza una regla por encima de todas. Pero es un mal hábito: hace el código difícil de mantener. Úsalo solo como último recurso, nunca como solución habitual.
