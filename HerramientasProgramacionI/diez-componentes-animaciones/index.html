🖱️ Pseudo-clases

⏱️ 35 minutos · "Los estados de un elemento" — :hover, :focus, :active, :disabled

🧠 La idea central

Una pseudo-clase es un estado especial de un elemento. No es algo que escribas en el HTML, sino algo que le pasa al elemento: el mouse está encima, tiene el foco del teclado, lo estás presionando, o está deshabilitado. Con CSS puedes cambiar su estilo en cada uno de esos estados.

Se escriben con dos puntos: :hover, :focus, :active, :disabled. Son la base de la interactividad visual.

🖱️ Las 4 pseudo-clases esenciales

Pseudo-claseCuándo se activaEjemplo típico
:hoverEl mouse está encimaCambiar color de un botón
:focusEl elemento tiene el foco (teclado)Resaltar un campo de texto
:activeSe está presionandoHundir un botón al hacer clic
:disabledEl elemento está deshabilitadoAtenuar un botón inactivo

⏳ Transiciones

⏱️ 35 minutos · "El cambio suave" — transition y sus propiedades

🧠 La idea central

Sin transición, un cambio de estilo es instantáneo: el botón salta de un color a otro. Con transition, el cambio se anima suavemente a lo largo de un tiempo. Es la diferencia entre un corte brusco y un fundido elegante.

La propiedad transition combina: qué propiedad cambia, cuánto dura y cómo acelera (easing).

💻 La sintaxis

estilos.css
.boton {
  background: #22d3ee;
  transition: background 0.3s ease;  /* propiedad, duración, easing */
}

.boton:hover {
  background: #a855f7;  /* este cambio ahora es suave */
}

⚠️ Error común: transicionar lo que no se puede

No todas las propiedades se pueden animar suavemente. display, por ejemplo, no transiciona (salta de golpe). Sí funcionan: color, background, transform, opacity, width, height. Usa transform y opacity para animaciones fluidas.

🔄 Transformaciones

⏱️ 35 minutos · "Mover, escalar y rotar" — translate, scale, rotate

🧠 La idea central

Las transformaciones cambian la posición, el tamaño o la rotación de un elemento sin afectar el flujo de la página. Son perfectas para efectos de hover: un botón que crece un poco, una tarjeta que se levanta, un icono que rota.

Se usan con la propiedad transform y tres funciones principales: translate(), scale() y rotate().

🔄 Las 3 transformaciones

📦 translate()

Mueve el elemento en X e Y. translate(20px, -10px) lo desplaza a la derecha y arriba.

🔍 scale()

Cambia el tamaño. scale(1.2) lo agranda un 20%. scale(0.8) lo encoge.

🔄 rotate()

Rota el elemento. rotate(45deg) lo gira 45 grados en el sentido de las agujas del reloj.

🎬 Animaciones

⏱️ 35 minutos · "Movimiento con vida propia" — @keyframes y animation

🧠 La idea central

Una transición va de un estado a otro (de A a B). Una animación puede tener muchos pasos y repetirse sola, sin necesidad de que el usuario haga algo. Se define con @keyframes (los fotogramas) y se aplica con animation.

Sirve para dar vida a la interfaz: un elemento que aparece, un icono que late, un fondo que se mueve.

💻 La sintaxis

estilos.css
@keyframes aparecer {
  from { opacity: 0; transform: translateY(20px); }
  to   { opacity: 1; transform: translateY(0); }
}

.tarjeta {
  animation: aparecer 0.6s ease;
}

🧭 UX y buenas prácticas

⏱️ 35 minutos · "Diseñar para personas" — sombras, bordes y experiencia de usuario

🧠 La idea central

La UX (experiencia de usuario) es cómo se siente usar tu página. Los efectos visuales —sombras, bordes redondeados, transiciones— no son decoración: son señales que guían al usuario. Un buen diseño comunica qué es clicable, qué es importante y qué está pasando.

✅ Las 5 reglas de oro de la UX

ReglaQué significa
1. Feedback visualTodo elemento interactivo debe reaccionar (hover, focus, active).
2. ConsistenciaMismos colores y efectos para acciones similares en toda la página.
3. Jerarquía visualSombras y tamaños para indicar qué es más importante.
4. AccesibilidadContraste suficiente y estados visibles para teclado y lector de pantalla.
5. SutilezaAnimaciones cortas y suaves, nunca bruscas ni excesivas.

⚠️ El botón "muerto"

Un botón que no cambia al pasar el mouse ni al hacer clic se siente roto. El usuario no sabe si funciona. Siempre agrega al menos un :hover y un :active a tus elementos interactivos. Es la señal mínima de que algo es clicable.
