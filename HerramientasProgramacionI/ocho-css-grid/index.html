🔲 El concepto de grid

⏱️ 35 minutos · "Filas y columnas" — por qué grid cambió la maquetación web

🧠 La idea central

Imagina una hoja cuadriculada: tiene filas (horizontales) y columnas (verticales). CSS Grid convierte un contenedor en una hoja cuadriculada donde cada celda puede ocupar una o varias filas y columnas.

Antes de Grid, maquetar una página era un dolor: se usaban tablas, flotantes (float) y trucos. Con Grid, defines la cuadrícula en el contenedor y los elementos se colocan solos.

❌ Sin grid

Usar float, position y márgenes negativos para alinear elementos. Frágil, difícil de mantener y poco responsive.

✅ Con grid

Defines display: grid y las columnas/filas. Los elementos se colocan en la cuadrícula de forma limpia y predecible.

👁️ Observa

Con display: block las celdas se apilan una debajo de otra. Activa grid para verlas en columnas.

💡 ¿Por qué importa?

Grid es bidimensional: controla filas y columnas a la vez. Flexbox es unidimensional (una fila o una columna). Por eso Grid es ideal para el layout general de la página, y flexbox para alinear elementos dentro de una celda.

📐 grid-template-columns y grid-template-rows

⏱️ 35 minutos · "El esqueleto de la cuadrícula" — definir cuántas columnas y filas hay

🧠 La idea central

Con display: grid solo activas la cuadrícula, pero no le dices cuántas columnas ni filas tiene. Para eso usas grid-template-columns (columnas) y grid-template-rows (filas). Cada valor que escribes crea una pista (track) de la cuadrícula.

📐 Las dos propiedades clave

PropiedadQué defineEjemplo
grid-template-columnsEl ancho de cada columna200px 1fr 1fr
grid-template-rowsEl alto de cada fila100px auto
gapEl espacio entre celdasgap: 10px

👁️ Observa

Con 1fr 1fr 1fr hay 3 columnas iguales. Cambia los valores para ver cómo se reparten el espacio.

💻 Código de ejemplo

estilos.css
.contenedor {
  display: grid;
  grid-template-columns: 200px 1fr 1fr;
  grid-template-rows: 100px auto;
  gap: 10px;
}

⚠️ Error común: olvidar el gap

Sin gap, las celdas quedan pegadas unas a otras y el diseño se ve apretado. El gap es el "aire" entre celdas: gap: 10px separa filas y columnas. También puedes usar row-gap y column-gap por separado.

📏 Unidades fr, auto, minmax y repeat

⏱️ 35 minutos · "Las herramientas de medida" — cómo repartir el espacio de forma inteligente

🧠 La idea central

Grid tiene unidades especiales para repartir el espacio. La más importante es fr (fracción): reparte el espacio disponible en partes iguales. Junto con auto, minmax() y repeat(), puedes crear layouts flexibles sin calcular píxeles a mano.

📏 Las 4 herramientas

HerramientaQué haceEjemplo
frFracción del espacio libre1fr 2fr → 1/3 y 2/3
autoSe ajusta al contenidoauto 1fr
minmax()Mínimo y máximo de una pistaminmax(200px, 1fr)
repeat()Repite una pista N vecesrepeat(3, 1fr)

🔁 repeat()

En vez de escribir 1fr 1fr 1fr 1fr, escribes repeat(4, 1fr). Más corto y fácil de leer.

grid-template-columns: repeat(4, 1fr);

📏 minmax()

Define un mínimo y un máximo. La pista nunca será más chica que el mínimo ni más grande que el máximo.

grid-template-columns: minmax(200px, 1fr);

🎮 Simulador: auto-fit vs auto-fill

Con repeat(auto-fit, minmax(...)) las columnas se crean solas según el ancho disponible. Toca los botones para ver la diferencia.

👁️ Observa

Con auto-fit las columnas se estiran para llenar el espacio. Cambia el mínimo para ver cómo cambia el número de columnas.

💡 Pro-Tip

auto-fit y auto-fill son casi iguales. La diferencia: auto-fit colapsa las columnas vacías y estira las que tienen contenido; auto-fill mantiene las columnas vacías reservando espacio. Para galerías responsive, auto-fit suele ser la mejor opción.

🗺️ grid-template-areas

⏱️ 35 minutos · "El mapa de la página" — nombrar áreas y colocarlas visualmente

🧠 La idea central

grid-template-areas te deja dibujar el layout con texto. Le das un nombre a cada zona (cabecera, menú, contenido, pie) y las colocas en una "matriz" de texto. Es la forma más visual de maquetar una página.

🗺️ El mapa de una página

estilos.css
.contenedor {
  display: grid;
  grid-template-areas:
    "cabecera cabecera"
    "menu     contenido"
    "pie      pie";
  grid-template-columns: 200px 1fr;
}

.cabecera { grid-area: cabecera; }
.menu     { grid-area: menu; }
.contenido{ grid-area: contenido; }
.pie      { grid-area: pie; }

⚠️ Error común: áreas con forma irregular

Cada área debe formar un rectángulo. No puedes tener un área en forma de "L". Si dibujas una forma irregular, el navegador ignora el layout y las áreas se rompen.

🖼️ Galería responsive y dashboard

⏱️ 35 minutos · "Manos a la obra" — dos layouts reales construidos con Grid

🎯 La misión

Vas a construir dos layouts clásicos: una galería responsive (que se adapta al ancho de la pantalla) y un dashboard (panel con cabecera, barra lateral y tarjetas de estadísticas). Ambos usan Grid.

🖼️ La galería responsive

La clave es repeat(auto-fit, minmax(200px, 1fr)): las columnas se crean solas según el espacio.

galeria.css
.galeria {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(200px, 1fr));
  gap: 15px;
}

.galeria img {
  width: 100%;
  border-radius: 8px;
}

📊 El dashboard

Un dashboard usa grid-template-areas para organizar cabecera, barra lateral y tarjetas.

dashboard.css
.dashboard {
  display: grid;
  grid-template-areas:
    "cabecera cabecera cabecera"
    "sidebar  stats    stats"
    "sidebar  stats    stats";
  grid-template-columns: 200px 1fr 1fr;
  gap: 15px;
}

.cabecera { grid-area: cabecera; }
.sidebar  { grid-area: sidebar; }
.stats    { grid-area: stats; }
