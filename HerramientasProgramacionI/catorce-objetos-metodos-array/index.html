📦 Objetos literales

⏱️ 35 minutos · "Un objeto agrupa datos que van juntos" — propiedades y métodos

🧠 La idea central

Imagina que quieres guardar los datos de una tarea: su título, su materia y si está completada. Podrías usar tres variables sueltas, pero es un lío. Un objeto te deja agruparlas en una sola "caja" con nombre.

Un objeto literal se escribe entre llaves { }. Dentro van propiedades (pares clave: valor) separadas por comas. Si una propiedad guarda una función, se llama método.

❌ Variables sueltas

Tres variables separadas que no saben que van juntas. Difícil de pasar de un lado a otro.

let titulo = "Estudiar"; let materia = "Matemáticas"; let completada = false;

✅ Un objeto

Todo agrupado en una sola variable. Claro y fácil de manejar.

const tarea = { titulo: "Estudiar", materia: "Matemáticas", completada: false };

💡 Propiedades vs métodos

Una propiedad guarda un dato (un texto, un número, un booleano). Un método guarda una función que hace algo con esos datos. Por ejemplo, tarea.mostrar() podría imprimir el título de la tarea.

🔑 Acceso a propiedades

⏱️ 35 minutos · "punto y corchetes" — dos formas de leer y escribir datos

🧠 La idea central

Una vez que tienes un objeto, necesitas leer y cambiar sus propiedades. Hay dos formas: con punto (objeto.propiedad) y con corchetes (objeto["propiedad"]). Ambas hacen lo mismo, pero los corchetes tienen un superpoder: permiten usar una variable como nombre de propiedad.

🔹 Notación de punto

Rápida y legible. Úsala cuando conoces el nombre exacto de la propiedad.

const tarea = { titulo: "Estudiar" }; tarea.titulo; // "Estudiar" tarea.titulo = "Repasar";

🔸 Notación de corchetes

Permite usar una variable o un nombre con espacios. Más flexible.

const clave = "titulo"; tarea[clave]; // "Estudiar" tarea["titulo"] = "Repasar";

🔁 forEach y map

⏱️ 35 minutos · "recorrer y transformar" — dos métodos para trabajar con arrays

🧠 La idea central

Un array guarda varios elementos. Para trabajar con ellos necesitas recorrerlos. forEach() ejecuta una función por cada elemento (para "hacer algo" con cada uno). map() también recorre, pero devuelve un array nuevo con los resultados (para "transformar" cada elemento).

🔁 forEach — hacer algo

Recorre y ejecuta una acción. No devuelve nada nuevo.

[1, 2, 3].forEach(n => { console.log(n); }); // 1 2 3

🗺️ map — transformar

Recorre y devuelve un array nuevo con cada elemento transformado.

const dobles = [1, 2, 3].map(n => n * 2); // [2, 4, 6]

🔍 filter, find y some

⏱️ 35 minutos · "filtrar, buscar y comprobar" — tres métodos que responden preguntas

🧠 La idea central

Estos tres métodos responden preguntas sobre un array usando una condición (una función que devuelve true o false):

  • filter() — devuelve un array con todos los elementos que cumplen la condición.
  • find() — devuelve el primer elemento que cumple la condición (o undefined).
  • some() — devuelve true si al menos uno cumple la condición.

⚠️ No confundas find con filter

find() devuelve un solo elemento (el primero que cumple). filter() devuelve un array con todos los que cumplen. Si buscas "la tarea con id 2", usa find. Si quieres "todas las tareas completadas", usa filter.

🗂️ Array de objetos

⏱️ 35 minutos · "datos reales" — combinar objetos y métodos de array

🧠 La idea central

En la vida real, casi nunca tienes un solo objeto: tienes muchos. Una lista de tareas, de productos, de estudiantes. Por eso guardas los objetos dentro de un array, y usas los métodos de array para trabajar con ellos. Es la combinación más poderosa de JavaScript.

💻 El patrón completo

tareas.js
const tareas = [
  { id: 1, titulo: "Estudiar", materia: "Matemáticas", completada: true },
  { id: 2, titulo: "Leer", materia: "Español", completada: false },
  { id: 3, titulo: "Practicar", materia: "Inglés", completada: true }
];

// Listar todas con forEach
tareas.forEach(t => console.log(t.titulo));

// Filtrar las completadas
const hechas = tareas.filter(t => t.completada);

// Buscar una por id
const tarea2 = tareas.find(t => t.id === 2);

// ¿Hay alguna completada?
const hayHechas = tareas.some(t => t.completada);

💡 El flujo de trabajo

1. Crear el array de objetos. 2. Listar con forEach. 3. Filtrar con filter. 4. Buscar con find. 5. Comprobar con some. Este es exactamente el patrón que usarás en tu proyecto final.
