🔧 Funciones

⏱️ 35 minutos · "Reutilizar en vez de repetir" — declaración clásica y funciones flecha

🧠 La idea central

Una función es un bloque de código con un nombre, que puedes llamar (ejecutar) todas las veces que quieras. En vez de copiar y pegar el mismo código 10 veces, lo escribes una vez dentro de una función y lo invocas cuando lo necesites.

Hay dos formas principales de declararlas: la declaración clásica (con la palabra function) y la función flecha (con =>), más corta y moderna.

📜 Declaración clásica

Usa la palabra function, un nombre y llaves { }. Es la forma más tradicional y legible.

function saludar() { console.log("¡Hola!"); }

⚡ Función flecha

Se guarda en una variable con const y usa la flecha =>. Más corta, ideal para funciones simples.

const saludar = () => { console.log("¡Hola!"); };

💡 ¿Por qué importa?

📥 Parámetros y retorno

⏱️ 35 minutos · "Entran datos, sale un resultado" — argumentos, parámetros y return

🧠 La idea central

Una función puede recibir datos (llamados parámetros) y devolver un resultado (con la palabra return). Los parámetros van entre los paréntesis; el return es lo que la función "entrega" a quien la llamó.

📦 Arrays

⏱️ 35 minutos · "Una caja con muchos compartimentos" — creación, índices y length

🧠 La idea central

Un array (o arreglo) es una lista ordenada de valores guardados en una sola variable. Se crea con corchetes [ ] y cada elemento tiene una posición llamada índice, que empieza en 0.

📦 Anatomía de un array

arrays.js
// Crear un array de tareas
const tareas = ["estudiar", "dormir", "comer"];

// Acceder por índice (empieza en 0)
console.log(tareas[0]);   // "estudiar"
console.log(tareas[1]);   // "dormir"

// Saber cuántos elementos tiene
console.log(tareas.length);  // 3

⚠️ Error común: el índice 0

Los arrays empiezan a contar en 0, no en 1. El primer elemento es array[0], el segundo es array[1], y el último es array[array.length - 1]. Olvidar esto es el error más frecuente al trabajar con arrays.

🧰 Métodos de array: push, pop, includes, indexOf

⏱️ 35 minutos · "Agregar, quitar y buscar" — las herramientas del CRUD

🧠 La idea central

Los arrays tienen métodos (funciones propias) para manipularlos. Los cuatro más usados son: push (agregar al final), pop (quitar el último), includes (¿existe este elemento?) e indexOf (¿en qué índice está?).

🧰 Los 4 métodos esenciales

MétodoQué haceEjemplo
push(x)Agrega x al final del arraytareas.push("leer")
pop()Quita y devuelve el último elementotareas.pop()
includes(x)Devuelve true si x está en el arraytareas.includes("leer")
indexOf(x)Devuelve el índice de x (o -1 si no está)tareas.indexOf("leer")

🔁 Recorrer arrays con for y for...of

⏱️ 35 minutos · "Visitar cada elemento" — bucles para leer todo el array

🧠 La idea central

Muchas veces necesitas recorrer un array: visitar cada elemento uno por uno para mostrarlo, sumarlo o transformarlo. Hay dos formas principales: el bucle for clásico (con índice) y el bucle for...of (más simple, recorre los valores directamente).

🔢 for clásico

Usa un índice i que va de 0 a length - 1. Te da control total sobre la posición.

for (let i = 0; i < tareas.length; i++) { console.log(tareas[i]); }

⚡ for...of

Recorre los valores directamente, sin índice. Más corto y legible cuando no necesitas la posición.

for (const tarea of tareas) { console.log(tarea); }

💻 Código de ejemplo: mostrar tareas en consola

mostrarTareas.js
const tareas = ["estudiar", "dormir", "comer"];

// Función que muestra todas las tareas en consola
function mostrarTareas(lista) {
  for (const tarea of lista) {
    console.log("📌 " + tarea);
  }
}

mostrarTareas(tareas);
// 📌 estudiar
// 📌 dormir
// 📌 comer

💡 ¿Cuál usar?

Si solo necesitas leer los valores, usa for...of: es más limpio. Si necesitas saber el índice (por ejemplo, para modificar un elemento en su posición), usa el for clásico.

// D. Buscar una tarea y recorrerlas todas
function buscarTarea(lista, nombre) {
  if (lista.includes(nombre)) {
    return 'La tarea "' + nombre + '" está en el índice ' + lista.indexOf(nombre);
  }
  return 'La tarea "' + nombre + '" no está en la lista.';
}
