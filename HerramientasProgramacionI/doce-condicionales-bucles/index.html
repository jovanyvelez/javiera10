🔀 Condicionales if/else

⏱️ 35 minutos · "Si pasa esto, haz aquello" — cómo el programa toma decisiones

🧠 La idea central

Un condicional es una instrucción que le dice al programa: "si se cumple esta condición, haz esto; si no, haz esto otro". Es exactamente como decidir en la vida real: si llueve, llevo paraguas; si no, no lo llevo.

En JavaScript se escribe con if (si), else if (si no, si...) y else (si no). La condición va entre paréntesis y el código a ejecutar entre llaves { }.

🔀 if / else if / else

La forma completa: evalúa varias condiciones en cadena. Solo se ejecuta una rama: la primera que sea verdadera.

if (edad >= 18) { // mayor de edad } else if (edad >= 13) { // adolescente } else { // niño/a }

❓ Operador ternario

Un if/else corto en una sola línea: condición ? valorSiVerdadero : valorSiFalso. Ideal para asignar un valor rápido.

const acceso = edad >= 18 ? "Puedes entrar" : "No puedes entrar";

⚖️ Comparaciones y operadores lógicos

⏱️ 35 minutos · "¿Es igual? ¿Es mayor? ¿Y si combino dos condiciones?"

🧠 La idea central

Un if necesita una condición que sea verdadera o falsa (un booleano). Para construir esa condición usamos comparaciones (===, !==, >, <) y operadores lógicos (&&, ||, !) para combinar varias.

⚖️ Los operadores de comparación

OperadorSignificadoEjemplo
===Igual estricto (mismo valor y tipo)5 === 5 → true
!==Diferente5 !== 3 → true
>Mayor que7 > 4 → true
<Menor que2 < 9 → true
>=Mayor o igual18 >= 18 → true
<=Menor o igual10 <= 9 → false

🔗 Los operadores lógicos

🔗 && (Y)

Verdadero solo si ambas condiciones son verdaderas.

edad >= 18 && tieneCedula

🔀 || (O)

Verdadero si al menos una condición es verdadera.

esAdmin || esEditor

🚫 ! (NO)

Invierte el valor: lo verdadero se vuelve falso y viceversa.

!estaLogueado

⚠️ Error común: = vs ===

Un solo = asigna un valor (x = 5). Tres === comparan (x === 5). Si escribes if (x = 5) en lugar de if (x === 5), el programa asignará 5 y la condición siempre será verdadera. ¡Un error clásico de principiante!

🔁 El bucle for

⏱️ 35 minutos · "Repite esto N veces" — automatizar tareas repetitivas

🧠 La idea central

Un bucle (o loop) repite un bloque de código varias veces. El bucle for es el más usado cuando sabes cuántas veces quieres repetir. Tiene tres partes: for (inicio; condición; incremento).

🔁 Las 3 partes del for

ParteQué haceEjemplo
InicioDeclara la variable contadoralet i = 0
CondiciónMientras sea verdadera, el bucle siguei < 5
IncrementoCambia el contador en cada vueltai++

💻 Código de ejemplo

bucle.js
// Imprime los números del 1 al 5
for (let i = 1; i <= 5; i++) {
  console.log(i);
}

// Recorre una lista simple
const frutas = ["manzana", "pera", "uva"];
for (let i = 0; i < frutas.length; i++) {
  console.log(frutas[i]);
}

🔄 while y do while

⏱️ 35 minutos · "Repite mientras se cumpla una condición" — bucles sin contador fijo

🧠 La idea central

El bucle while repite un bloque mientras una condición sea verdadera. A diferencia del for, no necesitas saber cuántas veces: se usa cuando la repetición depende de algo que cambia (un contador, una respuesta del usuario, un dato que llega).

🔄 while

Primero evalúa la condición y luego ejecuta. Si la condición es falsa desde el inicio, no se ejecuta ni una vez.

let n = 5; while (n > 0) { console.log(n); n--; }

🔁 do while

Primero ejecuta y luego evalúa. Se ejecuta al menos una vez, aunque la condición sea falsa.

let n = 5; do { console.log(n); n--; } while (n > 0);

⚠️ El bucle infinito

Si la condición de un while nunca se vuelve falsa, el bucle no termina jamás y el programa se congela. Siempre asegúrate de que algo dentro del bucle cambie la condición (como n-- en el ejemplo).

🛑 break y continue

⏱️ 35 minutos · "Controla el flujo del bucle" — salir o saltar una vuelta

🧠 La idea central

A veces necesitas controlar un bucle desde dentro: break lo detiene por completo, y continue salta a la siguiente vuelta sin ejecutar el resto del bloque. Son como los frenos y el acelerador de un bucle.

🛑 break

Sale del bucle inmediatamente. Útil para detenerse al encontrar lo que buscas.

for (let i = 1; i <= 10; i++) { if (i === 5) break; console.log(i); // 1 2 3 4 }

⏭️ continue

Salta a la siguiente vuelta, ignorando el resto del bloque actual.

for (let i = 1; i <= 5; i++) { if (i === 3) continue; console.log(i); // 1 2 4 5 }

💡 ¿Cuándo usarlos?

break: cuando buscas un elemento en una lista y lo encuentras, no necesitas seguir. continue: cuando quieres saltarte ciertos valores (por ejemplo, los números pares o los que no cumplen una condición).
