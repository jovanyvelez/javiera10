⚡ Qué es Bootstrap

⏱️ 35 minutos · "CSS escrito por otros" — qué es un framework y cómo se conecta

🧠 La idea central

Una biblioteca de JavaScript es un archivo con funciones que tú importas. Un framework CSS es lo mismo pero con estilos: una hoja de estilos enorme, ya escrita y probada, a la que solo le añades clases en el HTML. Bootstrap es el más famoso: lo usa Twitter, Instagram, Netflix y millones de sitios más.

La diferencia clave: en vez de escribir padding: 10px; border-radius: 30px; para cada botón, escribes class="btn btn-primary" y te ahorras esas dos líneas. Bootstrap no es magia: es CSS escrito por otras personas, con los mismos padding, display y box-shadow que estudiaste en la clase 6.

⚖️ La misma interfaz, de dos maneras

✍️ A mano (clases 5 y 6)

Repites padding, background, border y border-radius en cada botón. Funciona… pero si quieres cambiar el color de todos, tienes que editar many archivos.

Ventaja: entiendes cada línea.
Problema: se repite y pesa.

🧰 Con Bootstrap

Una sola clase por botón. Cambiar el color de todos es cambiar el archivo de Bootstrap (o una variable), no 40 botones.

Ventaja: rápido y consistente.
Cuidado: si no entiendes el CSS, no sabrás arreglar lo que se rompió.

🔌 Cómo se conecta: una línea en el <head>

Bootstrap se descarga de un servidor público llamado CDN (Content Delivery Network). Solo copias esta línea en el <head> de tu página, antes de tu propia hoja de estilos:

index.html
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">

  <!-- 1. Bootstrap: siempre PRIMERO -->
  <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.8/dist/css/bootstrap.min.css" rel="stylesheet">

  <!-- 2. Tu CSS: SIEMPRE DESPUÉS, para poder ganarle -->
  <link rel="stylesheet" href="styles.css">
</head>

⚠️ El orden importa: la cascada sigue mandando

¿Recuerdas la cascada de la clase 5? Cuando dos reglas de igual peso se contradicen, gana la última que se escribió. Bootstrap es CSS, no texto: si pones tu styles.css después del CDN, tú ganas. Por eso el orden es parte del método, no un detalle.

📦 Contenedores y columnas

⏱️ 35 minutos · "La retícula de Bootstrap" — container, row y col

🧠 La idea central

Bootstrap organiza la página con tres clases y nada más:

  • .container: una caja que limita el ancho y lo centra. Es el width: 1140px; margin: auto; que escribiste en la clase 6, pero mejor: se adapta sola al celular.
  • .row: una fila que parte el ancho en 12 columnas iguales.
  • .col-N: una columna que ocupa N de esas 12 partes.

Dentro de cada columna metes lo que quieras: una tarjeta, una imagen, un formulario entero. Por eso las columnas son tan útiles: el contenido se reparte, el ancho no se negocia.

⚠️ La regla de oro: los números de una fila suman 12 (o menos)

En una misma fila, las columnas suman 12: col-6 + col-6, col-4 + col-4 + col-4. Si te suman menos (por ejemplo col-6 solo), Bootstrap deja el hueco vacío a la derecha. Y si te suman más (por ejemplo col-8 + col-8), las que sobran bajan a la fila siguiente.

💡 container vs container-fluid

.container limita el ancho (para que en un monitor enorme las líneas no se hagan interminables). .container-fluid ocupa todo el ancho disponible. Los dos tienen las mismas columnas dentro; solo cambia la caja de fuera.

🔘 Botones y utilidades

⏱️ 35 minutos · "El box model con otro nombre" — btn, espaciado, colores y bordes

🧠 La idea central

Un botón de Bootstrap es una sola clase. class="btn btn-primary" significa: "hazte botón" + "píntame de azul". Y junto a eso hay las utilidades: clases sueltas que aplican una sola cosa, la más útil del framework.

🔘 .btn y sus variantes

Variantes de color · el ejemplo oficial
Con borde (outline) · sin relleno
Tamaños · clases extra Siempre btn primero: btn-primary solo no hace nada, porque .btn es la que pone el relleno, el borde y las esquinas redondeadas.

🧰 Las utilidades: una clase, una propiedad

Esta es la tabla más importante del día. Cada utilidad es una regla de CSS con nombre corto:

ClaseCSS realCapa del box model
p-3padding: 1remRelleno interno
mt-5margin-top: 3remMargen externo
mb-0margin-bottom: 0Margen externo
text-centertext-align: centerTipografía
fw-boldfont-weight: 700Tipografía
rounded-3border-radius: 1remBorde
borderborder: 1px solid #dee2e6Borde
shadowbox-shadow: 0 .5rem 1rem rgba(0,0,0,.15)Profundidad

La escala de espaciado siempre es la misma: 0 = nada · 1 = 0,25rem · 2 = 0,5rem · 3 = 1rem · 4 = 1,5rem · 5 = 3rem. Las letras son abreviaturas: p = padding, m = margin, t = top, b = bottom, s = start (izquierda), e = end (derecha).

💡 Por qué las utilidades son más útiles de lo que parecen

Escribir .mi-tarjeta { padding: 1rem; margin-top: 3rem; text-align: center; } es algo que repetirías en 20 sitios. Con utilidades pones class="card-body p-3 mt-5 text-center" y solo cambias donde debe cambiar. Bootstrap no te quita el box model: te quita la obligación de escribirlo 20 veces.

🗂️ Cards y navbar

⏱️ 35 minutos · "Cajas con nombre" — la tarjeta y la barra de navegación

🧠 La idea central

Una card es la caja de la clase 6 con nombre propio: borde redondeado, borde gris, sombra suave y padding interno. Bootstrap solo le pone el nombre para que tú no repitas el CSS. Y el navbar es la barra de navegación: logo a la izquierda, enlaces a la derecha.

Abre el index.html y el styles.css de tu proyecto/. Hoy no borras nada: conectas Bootstrap y vas quitando el CSS que se quedó sin trabajo.

1. Conecta el CDN — en el <head> de proyecto/index.html, pon el link de Bootstrap ARRIBA de tu <link> de estilos (de la clase 5):

proyecto/index.html — el <head>
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">

  <!-- Bootstrap: va PRIMERO -->
  <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.8/dist/css/bootstrap.min.css" rel="stylesheet">

  <!-- tu CSS: va DESPUÉS para poder ganarle -->
  <link rel="stylesheet" href="styles.css">
</head>

2. Añade clases, sin borrar las tuyas — Bootstrap se suma a lo que ya tienes; si una regla se contradicen, gana tu CSS (va después). Por eso puedes ir añadiendo clases poco a poco:

<!-- La barra de la clase 6, ahora con navbar -->

</header>

<!-- El botón de la clase 6, ahora con btn -->

<!-- Cada tarea: ahora es una card dentro de una columna -->
<div class="row g-3">
  <article class="tarea card h-100">
    <div class="card-body">
      <h3 class="card-title">Terminar matemáticas</h3>
      <p class="card-text">Categoría: estudio</p>

3. Guarda y mira. Si algo se ve raro, no es magia ni un error de Bootstrap: es tu CSS de la clase 6 peleándose con el nuevo. Ordena así:

  1. Abre Inspeccionar sobre el elemento que se ve mal.
  2. Si la regla que gana es de styles.css, bórrala o cámbiale el valor (ese es tu CSS, tú mandas).
  3. Si la regla que gana es de bootstrap.min.css, entonces falta una clase: vuelve al punto 2 y añádela.

Las utilidades son tu mejor aliado: añade mb-3, p-2, text-center o shadow donde haga falta y borra esas mismas reglas de tu styles.css. Cuenta cuántas líneas quitaste: ese es el ahorro real de Bootstrap. Si quieres un reto extra, mete tu proyecto dentro de un <div class="container"> para que en el monitor no se vea estirado.
