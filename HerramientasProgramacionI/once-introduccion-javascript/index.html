🧠 ¿Qué es JavaScript?

⏱️ 35 minutos · "El tercer pilar" — HTML estructura, CSS decora, JavaScript da vida

🧠 La idea central

JavaScript es un lenguaje de programación que se ejecuta en el navegador. Mientras HTML define qué hay en la página y CSS define cómo se ve, JavaScript define qué hace: reacciona a clics, valida formularios, anima elementos, carga datos y mucho más.

Es el único lenguaje que los navegadores entienden de forma nativa. Por eso, junto con HTML y CSS, forma la tríada de la web.

🏗️ HTML

La estructura: títulos, párrafos, imágenes, enlaces. Es el esqueleto.

🎨 CSS

El estilo: colores, tamaños, posiciones. Es la ropa y el maquillaje.

⚡ JavaScript

El comportamiento: lógica, reacciones, interactividad. Es el cerebro y los músculos.

💻 Cómo incluir JavaScript en tu página

El código JavaScript se escribe en un archivo .js y se enlaza desde el HTML con la etiqueta <script>. El atributo defer le dice al navegador que espere a que el HTML termine de cargar antes de ejecutar el script.

index.html
<!DOCTYPE html>
<html lang="es">
<head>
  <meta charset="UTF-8">
  <title>Mi página</title>
</head>
<body>
  <h1>Hola</h1>

  <!-- El script se carga al final, con defer -->
  <script src="script.js" defer></script>
</body>
</html>

💡 ¿Por qué defer?

Si el script se ejecuta antes de que el HTML cargue, no encontrará los elementos que quiere manipular. Con defer (o colocando el <script> al final del <body>) te aseguras de que la página ya existe cuando el código corre.

📦 Variables: let y const

⏱️ 35 minutos · "Cajas con nombre" — guardar datos para usarlos después

🧠 La idea central

Una variable es una caja con nombre donde guardas un valor para usarlo más tarde. En JavaScript moderno se declaran con let o const.

La diferencia clave: let permite cambiar el valor después, mientras que const es constante — una vez asignado, no se puede reasignar.

🔁 let — cambiable

Úsala cuando el valor va a cambiar: un contador, una puntuación, la edad.

let puntaje = 0; puntaje = 10; // ✅ se puede

🔒 const — constante

Úsala cuando el valor no debe cambiar: el nombre de un usuario, una configuración.

const nombre = "Ana"; nombre = "Luis"; // ❌ error

⚠️ Regla de oro

Usa const por defecto. Solo cambia a let cuando sepas que el valor va a cambiar. Esto evita errores: si intentas reasignar un const, JavaScript te avisa con un error en la consola.

🔢 Tipos de datos

🧠 La idea central

Cada valor en JavaScript tiene un tipo. Conocer los tipos te ayuda a saber qué puedes hacer con cada dato: sumar números, unir textos, decidir con verdaderos y falsos.

➕ Operadores y template literals

⏱️ 35 minutos · "Hacer cuentas y armar textos" — operadores aritméticos y cadenas con variables

🧠 La idea central

Los operadores te permiten hacer cálculos con los datos: sumar, restar, comparar. Y los template literals te permiten armar textos mezclando variables de forma limpia, usando comillas invertidas ` y ${...}.

➕ Operadores aritméticos

**Potencia2 ** 38

📝 Template literals

Antes, para unir texto y variables se usaba el +. Ahora usamos comillas invertidas y ${}:

script.js
const nombre = "Ana";
const edad = 15;

// Antes (concatenación con +)
console.log("Hola " + nombre + ", tienes " + edad + " años");

// Ahora (template literal)
console.log(`Hola ${nombre}, tienes ${edad} años`);

🖥️ La consola y console.log

⏱️ 35 minutos · "Tu mejor amiga" — ver qué hace tu código en tiempo real

🧠 La idea central

La consola del navegador es una herramienta donde JavaScript muestra mensajes. Con console.log() puedes imprimir valores para ver qué está pasando en tu código. Es la forma más rápida de depurar (encontrar errores).
