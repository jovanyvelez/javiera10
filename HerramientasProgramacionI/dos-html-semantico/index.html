🧱 ¿Qué es HTML semántico?

⏱️ 35 minutos · "Las etiquetas con significado" — por qué importa cómo nombras las cosas

🧠 La idea central

Imagina un libro sin títulos, sin capítulos, sin índice: solo párrafos uno tras otro. Podrías leerlo, pero sería un caos. El HTML semántico es ponerle títulos, capítulos y secciones a tu página: usar etiquetas que describen qué es cada parte, no solo cómo se ve.

Antes, la gente usaba <div> para todo: <div id="menu">, <div id="pie">. Funcionaba, pero el navegador no sabía qué era cada cosa. Hoy usamos etiquetas con nombre propio: <nav> para el menú, <footer> para el pie.

❌ HTML no semántico

Todo son <div> y <span>. El navegador no distingue un menú de un pie de página. Difícil de leer y de mantener.

✅ HTML semántico

Cada parte tiene su etiqueta: <header>, <nav>, <main>, <footer>. Claro para humanos y máquinas.

Un lector de pantalla es un programa que lee la página en voz alta para personas ciegas. Con HTML semántico, puede "saltar" al menú o al contenido principal. Toca los botones para ver la diferencia.

📐 Etiquetas estructurales

⏱️ 35 minutos · "El esqueleto de la página" — header, nav, main, section, article, aside, footer

🧠 La idea central

Una página web típica tiene un esqueleto que se repite en casi todos los sitios: una cabecera arriba, un menú, el contenido principal, quizás una barra lateral, y un pie abajo. HTML tiene una etiqueta para cada hueso de ese esqueleto.

🦴 Los 7 huesos del esqueleto

EtiquetaQué representa¿Cuántas por página?
<header>Cabecera: logo, título, introducción1 principal (o varias por sección)
<nav>Menú de navegación (enlaces)Las necesarias
<main>Contenido principal y único1 sola
<section>Sección temática con su propio títuloVarias
<article>Contenido independiente (una noticia, un post)Varias
<aside>Contenido secundario (barra lateral, publicidad)Varias
<footer>Pie: créditos, contacto, enlaces legales1 principal

🎮 Simulador: Arma el esqueleto

Ordena las etiquetas de arriba hacia abajo como aparecerían en una página real. Arrastra o usa las flechas.

🦴 Esqueleto de una página — orden correcto
? <header> — cabecera
? <nav> — menú
? <main> — contenido
? <aside> — barra lateral
? <footer> — pie

💻 Código de ejemplo

index.html
<body>
  <header>
    <h1>Mi Blog</h1>
  </header>

  <nav>
    <a href="#inicio">Inicio</a>
    <a href="#articulos">Artículos</a>
  </nav>

  <main>
    <section>
      <h2>Últimas noticias</h2>
      <article>
        <h3>Noticia 1</h3>
        <p>Contenido de la noticia...</p>
      </article>
    </section>
  </main>

  <aside>
    <h3>Publicidad</h3>
  </aside>

  <footer>
    <p>© 2026 Mi Blog</p>
  </footer>
</body>

⚠️ Error común: <main> repetido

La etiqueta <main> debe aparecer una sola vez por página: es el contenido principal y único. Si pones dos <main>, el navegador y los lectores de pantalla se confunden. Todo lo demás puede repetirse.

📋 Listas y enlaces

⏱️ 35 minutos · "ul, ol, li y a" — organizar información y conectar páginas

🧠 La idea central

Dos herramientas que usas en casi toda página: las listas (para agrupar elementos) y los enlaces (para conectar páginas). Son simples, pero dominarlas bien es la base de cualquier menú, índice o pie de página.

📋 Los dos tipos de lista

🔘 <ul> — lista desordenada

Elementos con viñetas (puntos). Para cuando el orden no importa: ingredientes, características, menú.

<ul> <li>Manzana</li> <li>Pera</li> <li>Uva</li> </ul>

🔢 <ol> — lista ordenada

Elementos numerados. Para cuando el orden sí importa: pasos de una receta, ranking, instrucciones.

<ol> <li>Lavar</li> <li>Pelar</li> <li>Cortar</li> </ol>

🔗 Enlaces internos y externos

Un enlace se crea con <a href="...">. El href puede apuntar a otra página (externo) o a una sección de la misma página (interno, con #).

enlaces.html
<!-- Enlace externo (a otra página web) -->
<a href="https://www.google.com">Ir a Google</a>

<!-- Enlace interno (a una sección de esta misma página) -->
<a href="#contacto">Ir a la sección de contacto</a>

<!-- La sección destino necesita un id -->
<section id="contacto">
  <h2>Contacto</h2>
</section>

🎮 Simulador: Clasifica lista o enlace

Para cada caso, decide si usarías una lista desordenada, una lista ordenada o un enlace.

🧩 ¿Qué usarías?

💡 Pro-Tip

Los menús de navegación casi siempre son una <ul> con enlaces <a> dentro de cada <li>. Es el patrón más usado de la web: una lista de enlaces.

🏠 Construye una landing page

⏱️ 35 minutos · "Manos a la obra" — estructura completa de una página de inicio

🎯 La misión

Una landing page es la página de inicio de un producto o servicio: lo primero que ve un visitante. Tiene una estructura clásica: encabezado, menú, sección principal (hero), sección de servicios/tarjetas y pie de página. Vas a armarla con HTML semántico.

🎮 Simulador: El constructor de landing pages

Selecciona las secciones que quieres incluir y observa cómo se arma la estructura HTML en vivo.

🏠 Constructor de landing page
<!-- Toca los botones para construir la página -->

💻 La landing page completa

landing.html
<body>
  <header>
    <h1>Mi Producto</h1>
    <p>El mejor producto del mundo</p>
  </header>

  <nav>
    <ul>
      <li><a href="#inicio">Inicio</a></li>
      <li><a href="#servicios">Servicios</a></li>
      <li><a href="#contacto">Contacto</a></li>
    </ul>
  </nav>

  <main>
    <section id="inicio">
      <h2>Bienvenido</h2>
      <p>Descubre lo que hacemos.</p>
    </section>

    <section id="servicios">
      <h2>Nuestros servicios</h2>
      <article><h3>Servicio 1</h3></article>
      <article><h3>Servicio 2</h3></article>
    </section>
  </main>

  <footer>
    <p>© 2026 Mi Producto</p>
  </footer>
</body>

🧭 Buenas prácticas de estructura

⏱️ 35 minutos · "Los hábitos de un buen desarrollador" — jerarquía, indentación y orden

🧠 La idea central

Escribir HTML que funcione es fácil. Escribir HTML que se entienda es un arte. Las buenas prácticas son hábitos que hacen tu código legible, mantenible y profesional.

✅ Las 5 reglas de oro

ReglaQué significa
1. Jerarquía de títulosUn solo <h1> por página; luego <h2>, <h3> en orden, sin saltos.
2. IndentaciónSangrar el código anidado para ver la estructura de un vistazo.
3. Etiquetas que cierranCerrar siempre </div>, </section>, etc.
4. Nombres con sentidoUsar id y class descriptivos: id="menu-principal", no id="x1".
5. Un solo <main>El contenido principal va en una única etiqueta <main>.

👁️ Resultado

⚠️ El salto de títulos

No saltes de <h1> a <h3> sin pasar por <h2>. Los títulos deben ir en orden jerárquico, como los capítulos de un libro: 1, 2, 3... no 1, 3, 5. Esto ayuda a los lectores de pantalla a entender la estructura.
