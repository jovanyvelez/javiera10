📦 El box model

⏱️ 35 minutos · "Todo es una caja" — content, padding, border y margin

🧠 La idea central

En CSS, todo elemento es una caja rectangular. Esa caja tiene cuatro capas, de adentro hacia afuera: el contenido (content), el relleno (padding), el borde (border) y el margen (margin). Entender estas cuatro capas es entender cómo se distribuye el espacio en una página.

Imagina un regalo: el contenido es el objeto, el padding es el papel de burbujas que lo protege por dentro, el border es la caja de cartón, y el margin es el espacio que dejas entre esta caja y las demás.

🎁 Las 4 capas de la caja

CapaQué esPropiedad
contentEl contenido real: texto, imagen, etc.width / height
paddingEspacio interno, entre el contenido y el bordepadding
borderLa línea que rodea el paddingborder
marginEspacio externo, entre el borde y otros elementosmargin

⚠️ El truco de box-sizing

Por defecto, width solo mide el contenido: si pones width: 200px y le sumas padding: 20px y border: 5px, la caja real mide 250px. Con box-sizing: border-box, el width incluye padding y border, y la caja mide exactamente lo que dijiste. Es el ajuste más útil que harás en CSS.

🧱 Display

⏱️ 35 minutos · "Cómo se comporta cada caja" — block, inline, inline-block y none

🧠 La idea central

La propiedad display decide cómo se comporta una caja en el flujo de la página: si ocupa todo el ancho, si se alinea en línea con otras, o si desaparece. Es la base de todo layout.

🔀 Los 4 valores principales

ValorComportamientoEjemplo típico
blockOcupa todo el ancho disponible y empieza en una línea nueva<div>, <p>, <h1>
inlineOcupa solo su contenido y fluye en línea; ignora width/height<span>, <a>
inline-blockFluye en línea pero respeta width/height y paddingBotones, tarjetas en fila
noneEl elemento desaparece por completo del flujoOcultar menús, modales

💡 Pro-Tip

El valor display: none elimina el elemento del flujo (no ocupa espacio). No lo confundas con visibility: hidden, que lo oculta pero sí deja su espacio reservado.

🧭 Posicionamiento

⏱️ 35 minutos · "Dónde va cada caja" — static, relative, absolute, fixed y sticky

🧠 La idea central

La propiedad position decide cómo se coloca un elemento en la página. Por defecto todo es static (fluye normal). Los otros valores te permiten mover elementos con top, right, bottom y left.

📍 Los 5 valores de position

ValorComportamiento¿Cuándo usarlo?
staticPosición normal (por defecto). Ignora top/leftLa mayoría de elementos
relativeSe mueve respecto a su posición originalAjustes finos sin sacar del flujo
absoluteSe posiciona respecto al ancestro posicionado más cercanoMenús desplegables, badges
fixedSe fija a la ventana; no se mueve al hacer scrollBarras de navegación fijas
stickySe comporta como relative hasta que "se pega" al hacer scrollEncabezados de tablas

⚠️ absolute necesita un ancestro posicionado

Un elemento con position: absolute se posiciona respecto al ancestro posicionado más cercano (uno con position: relative, absolute o fixed). Si no hay ninguno, se posiciona respecto a la página entera. Por eso es común poner position: relative al contenedor padre.

🎨 z-index y box-shadow

⏱️ 35 minutos · "Profundidad y relieve" — apilar capas y dar sombras

🧠 La idea central

Cuando los elementos se superponen, necesitas decidir cuál va encima. Eso lo controla z-index. Y para dar sensación de profundidad y relieve, usas box-shadow, que dibuja una sombra alrededor de la caja.

📚 z-index: el orden de apilamiento

El z-index es un número que decide qué elemento se dibuja encima de otro. Solo funciona en elementos posicionados (con position distinto de static). Un z-index mayor va encima de uno menor.

z-index.css
.caja-azul {
  position: relative;
  z-index: 1;   /* va debajo */
}

.caja-roja {
  position: relative;
  z-index: 2;   /* va encima */
}

💡 La sintaxis de box-shadow

box-shadow: desplazamientoX desplazamientoY desenfoque color;. Por ejemplo box-shadow: 0 10px 30px rgba(0,0,0,0.4); crea una sombra suave hacia abajo. Es la base de las tarjetas "flotantes" que ves en todas las apps modernas.

🧩 Componentes: card y botón

⏱️ 35 minutos · "Manos a la obra" — combinar box model, display y sombras

🎯 La misión

Ahora vas a combinar todo lo aprendido para crear dos componentes reales: una tarjeta (card) y un botón. Una card usa padding, border, margin y box-shadow. Un botón usa padding, border-radius y display. Son los bloques de construcción de casi toda interfaz moderna.

💻 La card y el botón

componentes.css
.card {
  width: 300px;
  padding: 20px;
  margin: 20px auto;
  border: 1px solid #1c3252;
  border-radius: 14px;
  box-shadow: 0 10px 30px rgba(0, 0, 0, 0.4);
  background: #0c1626;
}

.btn {
  display: inline-block;
  padding: 12px 24px;
  border: none;
  border-radius: 30px;
  background: linear-gradient(135deg, #22d3ee, #a855f7);
  color: #000;
  font-weight: 700;
  cursor: pointer;
}

.btn:hover {
  box-shadow: 0 6px 20px rgba(168, 85, 247, 0.5);
  transform: translateY(-2px);
}
