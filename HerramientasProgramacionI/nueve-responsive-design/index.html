📱 ¿Qué es responsive design?

⏱️ 35 minutos · "Una página, todas las pantallas" — por qué tu diseño debe adaptarse

🧠 La idea central

Imagina que tu página web es un líquido: si la viertes en un vaso angosto (celular) o en una bandeja ancha (monitor), se acomoda sola. El responsive design es exactamente eso: hacer que tu página detecte el tamaño de la pantalla y reorganice su contenido para verse bien en todas.

Antes, se hacían dos sitios: uno para computador y otro "móvil" (como m.misitio.com). Hoy, con responsive design, haces un solo sitio que se adapta solo.

❌ Sitio fijo (no responsive)

Ancho fijo de 1200px. En el celular se ve gigante, hay que hacer zoom y desplazarse de lado a lado. Frustrante.

✅ Sitio responsive

Se adapta al ancho de la pantalla: las columnas se apilan, el menú se compacta, las imágenes se encogen. Cómodo en todo.

📲 Mobile First y viewport

⏱️ 35 minutos · "Empieza por lo pequeño" — la estrategia y la etiqueta que lo hacen posible

🧠 La idea central

Mobile First es una estrategia: diseñas primero para la pantalla más pequeña (el celular) y luego, con media queries, vas agregando estilos para pantallas más grandes. Es más fácil agrandar un diseño simple que encoger uno complejo.

Y para que el navegador sepa el ancho real de la pantalla, necesitas la etiqueta viewport en el <head>.

📲 La etiqueta viewport

Sin esta línea, el celular "finge" tener una pantalla de 980px de ancho y encoge todo. Con ella, el navegador usa el ancho real del dispositivo.

index.html
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
</head>

⚠️ Error común: olvidar el viewport

Si olvidas la etiqueta <meta name="viewport">, tu página responsive no funcionará en celulares: se verá como una versión en miniatura de la de escritorio. Es la primera línea que debes revisar cuando algo no se adapta.

📲 La escalera de Mobile First

PasoQué hacesEjemplo
1. Base móvilEstilos para celular (una columna).tarjeta { width: 100%; }
2. TabletCon @media, dos columnas@media (min-width: 768px)
3. EscritorioCon @media, tres o más columnas@media (min-width: 1024px)

💡 Pro-Tip

En Mobile First usas min-width en las media queries: "a partir de este ancho, aplica esto". Empiezas simple y vas sumando. Es lo contrario de max-width, que dice "hasta este ancho, aplica esto" (el enfoque antiguo de escritorio primero).

📐 Media queries y breakpoints

⏱️ 35 minutos · "@media" — la herramienta que cambia el diseño según el ancho

🧠 La idea central

Una media query es una condición en CSS: "si la pantalla mide al menos 768px, aplica estos estilos". El ancho donde cambias el diseño se llama breakpoint (punto de quiebre). Es como un interruptor que enciende reglas nuevas cuando la pantalla cruza cierto tamaño.

📐 La sintaxis

estilos.css
/* Estilos base (móvil) */
.tarjeta { width: 100%; }

/* Tablet: a partir de 768px */
@media (min-width: 768px) {
  .tarjeta { width: 50%; }
}

/* Escritorio: a partir de 1024px */
@media (min-width: 1024px) {
  .tarjeta { width: 33.33%; }
}

⚠️ Breakpoints comunes

No hay breakpoints "oficiales", pero estos son los más usados: 480px (celulares pequeños), 768px (tablets), 1024px (laptops) y 1200px (escritorios grandes). Elige los que tu contenido necesite, no los que diga una lista.

📏 Unidades relativas

⏱️ 35 minutos · "% em rem vw vh" — medir en relación, no en píxeles fijos

🧠 La idea central

Los píxeles (px) son fijos: 100px son 100px en cualquier pantalla. Las unidades relativas miden en relación a algo: al contenedor, a la fuente, o a la pantalla. Por eso son la base del responsive design: crecen y se encogen con el contexto.

📏 Las 5 unidades que debes conocer

UnidadRelativa a...Uso típico
%El contenedor padreAnchos de columnas, imágenes
emEl tamaño de fuente del elementoMárgenes y padding que escalan con el texto
remEl tamaño de fuente de la raíz (html)Tipografía consistente en todo el sitio
vw1% del ancho de la ventanaTamaños que responden al ancho de pantalla
vh1% del alto de la ventanaSecciones a pantalla completa

🔒 Píxeles (fijos)

width: 300px; — siempre 300px, sin importar la pantalla. En un celular de 375px casi no deja espacio.

🔓 Relativas (flexibles)

width: 80%; — ocupa el 80% del contenedor, sea cual sea su tamaño. Se adapta sola.

💡 Pro-Tip: em vs rem

em se acumula: si un elemento está dentro de otro con fuente más grande, su em también crece. rem siempre mira la raíz (html), así que es más predecible. Regla práctica: usa rem para tamaños de fuente y em para padding/margen de componentes.

🎨 Variables CSS

⏱️ 35 minutos · ":root y --var" — guarda valores para reutilizarlos

🧠 La idea central

Una variable CSS es un valor con nombre que defines una vez y usas muchas veces. Se declaran en :root (la raíz del documento) con doble guion, y se usan con var(). Si cambias el valor en un solo lugar, cambia en toda la página.

🎨 La sintaxis

estilos.css
:root {
  --color-primario: #22d3ee;
  --fuente-principal: 'Segoe UI', sans-serif;
  --espaciado: 1rem;
}

body {
  font-family: var(--fuente-principal);
  color: var(--color-primario);
  padding: var(--espaciado);
}

💡 ¿Por qué usar variables?

Imagina que tu sitio usa el color morado en 50 lugares. Sin variables, tendrías que buscar y cambiar los 50. Con una variable, cambias una línea en :root y listo. Además, puedes redefinir variables dentro de una media query para cambiar el tema en pantallas pequeñas.
