🌍 Internet y la web

⏱️ 35 minutos · "La red de redes" — quién habla con quién

🧠 La idea central

Internet es una red gigante de computadores conectados entre sí por cables, fibra óptica y señales inalámbricas. La web es una de las cosas que viajan por esa red: páginas, imágenes, videos.

En esa conversación hay dos protagonistas: el cliente (tu navegador, que pide) y el servidor (un computador lejano, que responde). El navegador es el programa que usas para ver la web: Chrome, Firefox, Edge.

🌐 Internet

La red física: cables, routers, servidores. Es la "carretera" por donde viaja la información.

🕸️ La Web

El contenido que viaja por Internet: páginas, sitios, videos. Es lo que "circula" por la carretera.

🧭 Navegador

El programa que usas para ver la web: Chrome, Firefox, Edge. Es tu "ventana" a Internet.

💡 Pro-Tip

🧱 HTML, CSS y JavaScript

⏱️ 35 minutos · "Las 3 tecnologías de la web" — estructura, estilo y comportamiento

🧠 La idea central

Toda página web se construye con tres tecnologías que trabajan juntas. Como una casa: HTML son los muros (la estructura), CSS es la pintura (el estilo) y JavaScript es la electricidad (el comportamiento).

🏗️ HTML

Estructura. Define qué hay en la página: títulos, párrafos, enlaces, imágenes. Es el esqueleto.

🎨 CSS

Estilo. Colores, tamaños, márgenes. Hace que la página se vea bonita.

⚡ JavaScript

Comportamiento. Hace que los botones funcionen y la página responda.

📄 Estructura de una página HTML

⏱️ 35 minutos · "El esqueleto mínimo" — DOCTYPE, html, head y body

🧠 La idea central

Toda página HTML tiene un esqueleto mínimo que se repite siempre. Son cuatro piezas: la declaración <!DOCTYPE html>, la etiqueta <html>, la <head> (información invisible) y el <body> (lo que se ve).

🦴 Las 4 piezas del esqueleto

PiezaQué es¿Se ve?
<!DOCTYPE html>Le dice al navegador "esto es HTML moderno"No
<html>Envuelve toda la páginaNo
<head>Información: título, idioma, enlaces a estilosNo (salvo el título en la pestaña)
<body>Todo el contenido visibleSí

💻 El esqueleto mínimo

index.html
<!DOCTYPE html>
<html lang="es">
<head>
  <meta charset="UTF-8">
  <title>Mi primera página</title>
</head>
<body>
  <h1>¡Hola, mundo!</h1>
  <p>Esta es mi primera página web.</p>
</body>
</html>

🎮 Simulador: Arma el esqueleto

Ordena las piezas del esqueleto HTML de arriba hacia abajo.

🦴 Esqueleto HTML — orden correcto
? <!DOCTYPE html>
? <html>

⚠️ Error común: olvidar el <body>

Todo lo que quieras que se vea en la página debe ir dentro de <body>. Si lo pones en <head>, no se mostrará (o se mostrará mal). El <head> es solo para información "invisible".

🏷️ Etiquetas básicas

⏱️ 35 minutos · "h1-h6, p, a, br, hr" — las etiquetas que usarás siempre

🧠 La idea central

Las etiquetas son las palabras entre < > que le dicen al navegador qué mostrar. Hay decenas, pero estas cinco son las que usarás en casi toda página: encabezados (h1-h6), párrafos (p), enlaces (a), salto de línea (br) y línea horizontal (hr).

🏷️ Las 5 etiquetas esenciales

EtiquetaQué haceEjemplo
<h1> a <h6>Encabezados (h1 el más grande, h6 el más chico)<h1>Título</h1>
<p>Párrafo de texto<p>Hola</p>
<a>Enlace a otra página<a href="...">Ir</a>
<br>Salto de línea (no necesita cierre)Línea 1<br>Línea 2
<hr>Línea horizontal separadora<hr>

💻 Atributos y comentarios

Las etiquetas pueden tener atributos (información extra) y puedes dejar comentarios que el navegador ignora:

atributos.html
<!-- Esto es un comentario: el navegador lo ignora -->

<a href="https://www.google.com">Ir a Google</a>
<!--        ^^^^^^ el atributo href indica a dónde lleva el enlace -->

<img src="foto.jpg" alt="Mi foto">
<!--    ^^^^ ruta de la imagen   ^^^^ texto alternativo -->

💡 Pro-Tip: VS Code y Live Server

Para escribir HTML usa VS Code (editor gratuito). Con la extensión Live Server puedes ver tu página actualizarse en el navegador cada vez que guardas, sin recargar a mano. Es la forma más cómoda de trabajar.
