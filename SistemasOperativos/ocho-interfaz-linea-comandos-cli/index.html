💻 ¿Qué es la línea de comandos?

⏱️ 40 minutos · "Hablar con el SO" — Bash vs PowerShell, el prompt y por qué existe la terminal

🧠 La idea central

La interfaz gráfica (ventanas, iconos, el ratón) es cómoda, pero la línea de comandos (CLI) es directa: escribes una orden, el SO la cumple y responde con texto. Es el modo original de usar un ordenador y sigue siendo la herramienta favorita de quien administra sistemas, programa o automatiza tareas, porque es más rápida, potente y scriptable (puedes encadenar comandos). En esta clase la usaremos sin riesgo en un simulador dentro del navegador.

🐧 Bash vs 🪟 PowerShell: dos dialectos

La línea de comandos no es única: cada sistema trae la suya.

Aspecto🐧 Linux · Bash🪟 Windows · PowerShell
Prompt (el "cartel" que te invita a escribir)estudiante@javiera10:~$PS C:\Users\Estudiante>
Separador de rutas/ (barra normal)\ (barra invertida)
¿Dónde estoy?pwdpwd o Get-Location
Listar archivoslsdir o Get-ChildItem (ls es alias)
Cambiar de carpetacdcd o Set-Location
Mayúsculas importanSí: LS ≠ lsNo: CD = cd

💡 PowerShell es amable con quien viene de Linux: muchos comandos de Bash (ls, cd, pwd, cp) son alias que funcionan, aunque con diferencias (¡ojo con ls -la!).

🔍 Anatomía del prompt

estudiante@javiera10:~$ pwd
/home/estudiante
  • estudiante → tu nombre de usuario.
  • @javiera10 → el nombre de la máquina (host).
  • :~ → la carpeta donde estás. ~ es un atajo para tu carpeta personal (/home/estudiante).
  • $ → el final del prompt; detrás escribes el comando. (En Windows, PS ...> cumple el mismo rol.)

🧭 Navegación: ¿dónde estoy y a dónde voy?

⏱️ 50 minutos · pwd, ls/dir y cd — rutas absolutas y relativas, . y ..

🧠 La idea central

Antes de crear o borrar algo, necesitas saber dónde estás y cómo llegar a otra carpeta. Tres comandos son tu brújula: pwd (¿dónde estoy?), ls/dir (¿qué hay aquí?) y cd (cambiar de carpeta). El resto de la consola se construye sobre estos tres.

📍 pwd — "print working directory"

Imprime la ruta absoluta de la carpeta actual.

$ pwd
/home/estudiante/documentos
PS C:\Users\Estudiante> pwd
C:\Users\Estudiante\Documentos

📋 ls / dir — listar contenido

Linux (Bash)Windows (PowerShell)Qué hace
lsdir / lsLista archivos y carpetas
ls -ldir (siempre largo)Formato largo (detalles)
ls -adir -ForceIncluye ocultos (empiezan con .)
ls documentosdir documentosLista el contenido de esa subcarpeta

⚠️ En PowerShell, ls -la no funciona: ls es un alias de Get-ChildItem y no acepta las banderas de Bash. El simulador te lo recordará amablemente si lo intentas.

🚪 cd — "change directory"

Te mueve a otra carpeta. Acepta rutas absolutas (desde la raíz) y relativas (desde donde estás).

$ cd /home/estudiante/descargas # absoluta
$ cd documentos # relativa: entra a la subcarpeta
$ cd .. # sube a la carpeta padre
$ cd # sin argumentos: vuelve a tu home

`.` y `..`: los dos atajos mágicos

  • . → la carpeta actual.
  • .. → la carpeta padre (la que contiene a la actual).
  • ../.. → sube dos niveles. Y cd ../../descargas sube dos y baja a descargas.

🛡️ ¿Y si te pasas? cd ../../../.. desde el home simplemente te deja en la raíz (/ en Linux, C:\ en Windows). El SO no se rompe: no puedes subir más arriba de la raíz.

🧩 Comprobemos lo aprendido

1. Estás en /home/estudiante/documentos y escribes cd ... ¿Dónde quedas?

2. ¿Qué comando lista los archivos incluidos los ocultos en Bash?

3. Escribes cd /etc/../../../.. en Linux. ¿Qué pasa?

📂 Crear, leer y borrar

⏱️ 50 minutos · mkdir, touch / New-Item, cat / type, rm / del, rmdir — y el peligro de un espacio de más

🧠 La idea central

Ya sabes moverte. Ahora vamos a modificar el sistema de archivos: crear carpetas y archivos, leer su contenido y borrar lo que no necesitas. Estos comandos son poderosos y, en un equipo real, no piden confirmación: lo que borras con rm no va a la papelera. Por eso los practicamos en el simulador.

📁 Crear carpetas — mkdir

$ mkdir Proyectos
PS C:\Users\Estudiante> mkdir Proyectos

Funciona igual en ambos. En PowerShell, mkdir es un atajo de New-Item -ItemType Directory.

📄 Crear archivos — touch / New-Item

$ touch notas.txt # Linux: crea archivo vacío
PS C:\Users\Estudiante> New-Item -ItemType File notas.txt

✍️ Escribir contenido — echo con redirección

$ echo "Hola clase 8" > notas.txt
$ echo "segunda línea" >> notas.txt # >> añade sin borrar
  • > sobreescribe el archivo (lo deja solo con el nuevo contenido).
  • >> añade al final (append).

📖 Leer archivos — cat / type

$ cat notas.txt
Hola clase 8
segunda línea
PS C:\Users\Estudiante> type notas.txt

🗑️ Borrar — rm / del, rmdir

Linux (Bash)Windows (PowerShell)Qué borra
rm notas.txtdel notas.txtUn archivo
rmdir vaciarmdir vaciaUna carpeta vacía
rm -r Proyectosdel Proyectos -RecurseUna carpeta con todo su contenido

⚠️ El espacio que lo borra todo

El comando rm -rf / carpeta (con un espacio después de /) significa "borra la raíz y además carpeta". En un equipo real eso destruye el sistema. La regla de oro: si una ruta tiene espacios, ponla entre comillas: rm -rf "/mis documentos". En el simulador estás a salvo, pero graba el hábito.

🧩 Comprobemos lo aprendido

1. ¿Qué diferencia hay entre > y >> al escribir en un archivo?

2. En Linux, ¿cómo borras una carpeta que tiene archivos dentro?

3. ¿Por qué conviene poner entre comillas una ruta con espacios al borrarla?

🛠️ Taller: "El backup de Mateo"

⏱️ 35 minutos · Caso práctico entregable — consola en acción

📜 El caso

Mateo tiene un USB lleno de tareas desordenadas. Quiere organizarlas: crear una carpeta Backup, copiar (en el simulador: recrear) sus archivos importantes dentro, verificar el contenido y borrar el original. No recuerda cómo hacerlo con el ratón… pero tú acabas de aprender la consola. Ayúdalo paso a paso.

📝 Instrucciones

  1. Abre el simulador en la pestaña 🎯 Retos CLI (o úsalo aquí mismo abajo en el navegador si tu docente lo habilita).
  2. Completa en orden: pwd → mkdir Backup → crea dentro los archivos tarea1.txt, tarea2.txt → escribe en cada uno una línea con echo → verifica con cat → borra los originales.
  3. Responde las preguntas del taller más abajo.
